# TaskNest

TaskNest is a minimal, modern, and fully responsive task management app built with React, Vite, and Tailwind CSS.

## Features
- Add, edit, and delete tasks
- Organize tasks by category and due date
- Manage subtasks and track progress
- Mark tasks as complete or delete them
- View history of completed and deleted tasks
- One-click reset to clear all data
- Works great on mobile and desktop
- All data is stored locally in your browser for privacy

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-github-repo/tasknet-react.git
   cd tasknet-react
   ```
2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```
3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```
4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Usage
- Click **Add +** to create a new task. Fill in the task name, category, and due date.
- Click the settings icon to view history, reset all data, or read about the app.
- Click a task's checkmark to mark it as complete. Add subtasks for more detailed tracking.
- Deleted and completed tasks are saved in the history section.
